# Rimfall Arena

충격을 누적시켜 상대를 더 멀리 밀어내는 2–6인 자유 대전입니다. `another-game`은 독립 Godot 프로젝트입니다.

## 친구들과 플레이

1. 각 PC에서 같은 Windows 빌드인 `build/RimfallArena-v0.8.exe`를 실행합니다. 에디터 설치 없이 이 파일 하나로 실행할 수 있습니다.
2. 방장은 닉네임을 입력하고 **친구 방 만들기**를 누릅니다. 기본 포트는 **UDP 7410**입니다.
3. 방장은 대기실 목록에서 친구가 접속할 수 있는 네트워크 주소를 선택하고 **주소 복사**를 눌러 공유합니다. 참가자는 그 주소를 호스트 IP 칸에 붙여넣고 **방 참가**를 누릅니다. `주소:포트`를 붙여넣으면 입력된 포트도 자동으로 적용됩니다.
4. 방장이 **대전 시작**을 누르면 상점이 열립니다. 각자 **구매 완료 · 준비**를 누르거나 25초가 지나면 전투가 시작됩니다.

같은 Wi-Fi나 유선 LAN에서는 방장 PC의 해당 네트워크 주소를 사용합니다. 다른 장소에서 만나려면 이미 구성된 같은 가상 LAN의 주소나 방장에게 직접 도달 가능한 주소와 UDP 포트가 필요합니다. 접속이 막히면 방장 PC에서 게임의 UDP 수신이 허용되는지 확인하세요. 같은 PC에서 두 창을 열어 확인할 때는 `127.0.0.1:7410`을 사용합니다.

메인 화면의 **봇과 연습**으로 상점과 전투를 바로 시험할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 또는 누르고 있기 | 기본 스킬 **펄스 탄** 발사 |
| Q | 투사체 견제 — 충격파, 관통창, 삼연탄, 회수 디스크, 궤도 탄, 추적 신호탄 |
| E | 범위 공격 — 낙뢰 표식, 반발 고리, 균열선, 분열 표식 |
| R | 결정타 — 중격탄, 중력 붕괴, 반동포, 과충전 볼트 |
| F | 유틸리티 — 고정장, 응급 수리, 충격 정화, 반사막, 회귀 앵커, 가속 저장기 |
| Space | 이동기 — 점멸 추진, 긴급 복귀, 몸통박치기, 이중 도약 |

## 전투와 라운드

- 공격 스킬은 체력을 깎으며 충격량을 올립니다. 충격량이 높은 상대가 같은 공격에 더 멀리 밀려납니다. 투사체끼리 닿으면 둘 다 사라집니다.
- 전투 카메라는 내 캐릭터를 따라갑니다. 탈락하면 남은 생존자를 따라가며 관전합니다.
- 전장은 **1,400 × 1,400** 크기의 정사각형입니다. 전투 중 화면 밖의 상대는 화면 가장자리의 작은 화살표로 방향을 표시합니다.
- 안전선 밖에서는 기본 초당 14의 체력을 잃습니다. 체력이 남아 있으면 이동하거나 Space 이동기를 사용해 복귀할 수 있습니다. 체력이 0이 되면 탈락합니다. 안전선은 라운드 도중 좁아지고, 75초부터는 모든 생존자가 초당 최소 12의 체력을 잃습니다.
- 시작 골드는 **220 G**입니다. 슬롯의 첫 구매로 고른 스킬을 경기 끝까지 사용합니다. 정비 중 장착한 스킬을 최대 3레벨까지 강화할 수 있습니다. 새 경기에서는 슬롯마다 다시 고를 수 있습니다.
- 회수 디스크는 좁은 궤도를 왕복하며 돌아올 때 피해가 줄어듭니다. 중력 붕괴는 폭발 범위 안의 투사체를 중심 쪽으로 굽힙니다. 반사막은 짧은 시간 안에 맞는 첫 투사체 한 발을 약화시켜 되돌려 보냅니다.
- 몸통박치기는 돌진 중 처음 닿은 상대에게 피해와 넉백을 줍니다. 접촉 속도가 빠를수록 강해지고, 돌진 도중 피격되면 체력이 줄고 박치기 판정이 끊깁니다.
- 회귀 앵커는 첫 F 입력에서 위치를 기록하고, 유효 시간 안에 다시 누르면 그 위치로 이동합니다. 체력과 충격량은 현재 상태로 남습니다. 이중 도약은 첫 돌진 뒤 0.9초 안에 Space를 한 번 더 눌러 별도의 방향으로 돌진합니다.
- 라운드 마지막 생존자가 1승을 얻습니다. 다음 라운드 골드는 **킬 → 가한 피해량** 순으로 정하며, 동점 순위는 같은 보상을 받습니다. 골드와 구매 내역은 경기 중 이어집니다.
- 5라운드 후 **승수 → 총 킬 → 총 피해량** 순으로 최종 우승자를 정합니다.

## 장비 상점

정비 중 **ITEM · 장비**에서 종류가 다른 장비를 최대 **3개** 장착할 수 있습니다. 장비를 판매하면 구매가의 절반을 돌려받습니다. 함께 적용되는 배율은 곱하고, 비상 캡슐의 발동 여부는 라운드마다 초기화됩니다.

| 장비 | 가격 | 효과 |
| --- | --- | --- |
| 절연 코일 | 90 G | 장외 피해 25% 감소 |
| 비상 캡슐 | 110 G | 라운드 첫 장외 진입 시 2.5초간 장외 피해 60% 감소 |
| 경량 프레임 | 115 G | 기본 이동속도 12% 증가, 받는 넉백 20% 증가 |
| 중량 프레임 | 120 G | 받는 넉백 18% 감소, 투사체 사거리 15% 감소 |
| 충격 완충기 | 105 G | 피격 시 충격 누적 20% 감소, 기본 이동속도 5% 감소 |
| 장거리 조준기 | 115 G | 투사체 사거리 18% 증가, 투사체 속도 10% 감소 |

## 개발 실행 및 검증

Godot 4.7.2에서 `project.godot`을 가져와 F5로 실행합니다. 아래 명령은 이 폴더에서 실행하며 `godot`은 설치된 실행 파일 경로로 바꿀 수 있습니다.

```powershell
godot --headless --path . --script res://tests/smoke.gd
godot --headless --path . --export-release "Windows Desktop" build/RimfallArena-v0.8.exe
```

스모크 테스트는 상점·넉백·장외 규칙과 로컬 UDP를 통한 5라운드 플레이 흐름을 검증합니다. 저장된 빌드가 없는 상태에서 내보내려면 먼저 `build` 폴더를 생성합니다.
