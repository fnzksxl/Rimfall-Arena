# Rimfall Arena

충격을 누적시켜 상대를 더 멀리 밀어내는 2–6인 자유 대전입니다. `another-game`은 독립 Godot 프로젝트입니다.

## 친구들과 플레이

1. 각 PC에서 같은 Windows 빌드인 `build/RimfallArena-v0.11.1.exe`를 실행합니다. 에디터 설치 없이 이 파일 하나로 실행할 수 있습니다.
2. 방장은 닉네임과 **개인전 / 팀전**을 선택한 뒤 방 만들기 버튼을 누릅니다. 기본 포트는 **UDP 7410**입니다.
3. 방장은 대기실 목록에서 친구가 접속할 수 있는 네트워크 주소를 선택하고 **주소 복사**를 눌러 공유합니다. 참가자는 그 주소를 호스트 IP 칸에 붙여넣고 **방 참가**를 누릅니다. `주소:포트`를 붙여넣으면 입력된 포트도 자동으로 적용됩니다.
4. 팀전 참가자는 자동으로 두 팀에 배정되며 대기실 버튼으로 팀을 옮길 수 있습니다. 팀당 최대 3명이고 양 팀이 모두 참가하며 인원 차이가 1명 이하일 때 시작할 수 있습니다.
5. 방장이 **대전 시작**을 누르면 상점이 열립니다. 각자 **구매 완료 · 준비**를 누르거나 25초가 지나면 전투가 시작됩니다.

같은 Wi-Fi나 유선 LAN에서는 방장 PC의 해당 네트워크 주소를 사용합니다. 다른 장소에서 만나려면 이미 구성된 같은 가상 LAN의 주소나 방장에게 직접 도달 가능한 주소와 UDP 포트가 필요합니다. 접속이 막히면 방장 PC에서 게임의 UDP 수신이 허용되는지 확인하세요. 같은 PC에서 두 창을 열어 확인할 때는 `127.0.0.1:7410`을 사용합니다.

혼자 연습할 때 메인 화면에서 모드와 봇 수를 선택합니다. **개인전**은 봇 1~5마리를 상대합니다. **팀전**은 봇 1·3·5마리를 넣어 각각 1대1·2대2·3대3으로 진행합니다. 개인전 봇끼리도 서로 싸우며, 탈락한 뒤 남은 봇의 전투를 관전할 수 있습니다.

## 전투와 라운드

- 공격 스킬은 체력을 깎으며 충격량을 올립니다. 충격량이 높은 상대가 같은 공격에 더 멀리 밀려납니다. 투사체끼리 닿으면 둘 다 사라집니다.
- 전투 카메라는 내 캐릭터를 따라갑니다. 탈락하면 남은 생존자를 따라가며 관전합니다.
- 초기 안전 구역은 **1,400 × 1,400**, 장외 공간을 포함한 전체 맵은 **2,880 × 2,880**입니다. 투사체는 안전선을 통과하며 충돌이 없으면 맵의 고정 경계에서 사라집니다. 장판과 지점 지정 스킬은 기존 시전 거리와 반경을 사용합니다. 화면 밖의 상대는 화면 가장자리 화살표로 표시합니다.
- 안전선 밖에서는 기본 초당 14의 체력을 잃습니다. 체력이 남아 있으면 이동하거나 Space 이동기를 사용해 복귀할 수 있습니다. 체력이 0이 되면 탈락합니다. 안전선은 라운드 도중 좁아지고, 75초부터는 모든 생존자가 초당 최소 12의 체력을 잃습니다.
- 시작 골드는 **220 G**입니다. 슬롯의 첫 구매로 고른 스킬을 경기 끝까지 사용합니다. 정비 중 장착한 스킬을 최대 3레벨까지 강화할 수 있습니다. 새 경기에서는 슬롯마다 다시 고를 수 있습니다.
- 회수 디스크는 일정 거리를 날아간 뒤 반대 방향으로 꺾이며, 피해가 줄어든 채 맵 경계까지 진행합니다. 궤도 탄과 추적 신호탄은 처음에만 방향을 조정하고 이후 직진합니다. 중력 붕괴는 폭발 범위 안의 투사체를 중심 쪽으로 굽힙니다. 반사막은 짧은 시간 안에 맞는 첫 투사체 한 발을 약화시켜 되돌려 보냅니다.
- 몸통박치기는 돌진 중 처음 닿은 상대에게 피해와 넉백을 줍니다. 접촉 속도가 빠를수록 강해지고, 돌진 도중 피격되면 체력이 줄고 박치기 판정이 끊깁니다.
- 회귀 앵커는 첫 F 입력에서 위치를 기록하고, 유효 시간 안에 다시 누르면 그 위치로 이동합니다. 체력과 충격량은 현재 상태로 남습니다. 이중 도약은 첫 돌진 뒤 0.9초 안에 Space를 한 번 더 눌러 별도의 방향으로 돌진합니다.
- 개인전은 라운드 마지막 생존자가 1승을 얻습니다. 5라운드 뒤 **승수 → 총 킬 → 총 피해량** 순으로 최종 우승자를 정합니다.
- 팀전은 상대 팀이 전원 탈락하면 1승을 얻습니다. 5라운드 뒤 승수가 많은 팀이 우승하고, 승수가 같으면 공동 우승입니다. 한 팀 전원이 연결을 종료하면 상대 팀이 우승합니다.
- 팀원끼리 피해, 넉백, 상태 이상이 적용되지 않습니다. 서로 다른 아군이 발사한 탄은 통과하고, 적 탄과 충돌하면 양쪽 탄이 사라집니다. 아군은 우리 팀의 은신 플레이어를 볼 수 있습니다.
- 다음 라운드 골드는 두 모드 모두 개인의 **킬 → 가한 피해량** 순으로 정하며, 동점 순위는 같은 보상을 받습니다. 골드와 구매 내역은 경기 중 이어집니다.

## 장비 상점

정비 중 **ITEM · 장비**의 **기동·장외**, **방어·회복** 탭에서 종류가 다른 장비를 최대 **3개** 장착할 수 있습니다. 장비를 판매하면 구매가의 절반을 돌려받습니다. 함께 적용되는 배율은 곱하고, 비상 캡슐과 차폐 전지의 발동 여부는 라운드마다 초기화됩니다.

| 장비 | 가격 | 효과 |
| --- | --- | --- |
| 절연 코일 | 90 G | 장외 피해 25% 감소 |
| 비상 캡슐 | 110 G | 라운드 첫 장외 진입 시 2.5초간 장외 피해 60% 감소 |
| 경량 프레임 | 115 G | 기본 이동속도 12% 증가, 받는 넉백 20% 증가 |
| 중량 프레임 | 120 G | 받는 넉백 18% 감소, 투사체 속도 15% 감소 |
| 충격 완충기 | 105 G | 피격 시 충격 누적 20% 감소, 기본 이동속도 5% 감소 |
| 재생 망토 | 115 G | 피격 3초 뒤부터 안전선 안에서 초당 체력 1.5 회복. 과부하 중에는 정지 |
| 완충 흉갑 | 125 G | 주고받는 직접 피해 2 감소. 타격당 최소 피해 1 |
| 흡수 가면 | 130 G | 상대에게 실제로 준 직접 피해의 20%만큼 체력 회복. 받는 직접 피해 10% 증가 |
| 차폐 전지 | 140 G | 라운드 첫 직접 피격의 피해와 넉백 40% 감소 |

재생 망토는 원본의 회복 장비, 완충 흉갑은 Warden, 흡수 가면은 Scourge에 흡혈을 부여하는 장비, 차폐 전지는 Aegis의 발동형 피해·넉백 감소에서 가져왔습니다. 여기서는 흡혈에 직접 공격을 쓰고, 차폐는 피격 시 자동으로 발동합니다. [공식 1.01b 맵](https://www.warlockbrawl.com/download/) · [Warden](https://www.warlockbrawl.com/handbook/warden.html) · [Aegis](https://www.warlockbrawl.com/handbook/aegis.html)

## 개발 실행 및 검증

Godot 4.7.2에서 `project.godot`을 가져와 F5로 실행합니다. 아래 명령은 이 폴더에서 실행하며 `godot`은 설치된 실행 파일 경로로 바꿀 수 있습니다.

```powershell
godot --headless --path . --script res://tests/smoke.gd
```
